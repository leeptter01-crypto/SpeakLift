## 已完成

- 英语、粤语与原创 TOEFL 风格练习内容，单词、听力、跟读分阶段呈现。
- 独立句库、点击查看中文、复习队列，以及达标后的明确“继续”按钮。
- 一个跟读入口同时负责录音与可用时的语音识别；同一阶段显示本次录音回放。
- 录音、授权等待和结束处理均有时间上限；识别服务异常时仍保留已录音频。
- 用户已确认 v13 可以录制。录音成功不等于语音识别服务可用，也不等于发音评估通过。
- 36 项录音、识别生命周期和学习进度自动测试通过；这些测试含模拟设备，不能替代真人测试。
- 手机与电脑的 PWA 安装入口、Windows 启动器，以及按本地账号保存的学习记录。

## 待完成与能力边界

- 明确并展示评分标准。目前 95% 是识别文字匹配度，不是真实声学发音准确率。
- 用获得许可的真人朗读替换浏览器合成朗读，补充多个真人声音和逐条来源标注。当前尚未实现，不能把现有合成声音称为真人。
- 浏览器原生语音识别可能因网络或服务不可用而失败。没有识别文字时不得编造评分或自动过关。
- 当前注册验证码、邮箱/手机/Google 标识及密码流程为本地演示。真实短信/邮件发送、Google OAuth 和多设备同步需要服务端与供应商配置。
- 学习记录位于用户浏览器本地存储，录音仅在页面内存中；同步 GitHub 源码不会上传这些个人数据。
- 内置 TOEFL 内容为原创练习，并非指定图书全文或配套音频。后续内容包须具备适当授权。
